# Spanish Master Deck — Offline Package

Everything works without internet once downloaded.

## Files

- **spanish-master-deck-offline.html** — The full flashcard app (1,214 cards:
  514 phrases, 100 verbs, 100 adjectives, 500 nouns). Open in any browser.
  On iPhone: save to the Files app and open from there.
  Pronunciation uses your device's built-in Spanish voices.
- **spanish-flashcard-setup-prompt.md** — Give this to a friend's AI assistant
  to rebuild the whole system for themselves.
- **100-essential-spanish-phrases.pdf** — Printable phrase deck.
- **deck-data/** — All card data as JSON (phrases, verbs, adjectives, nouns).

## iPhone offline use

1. Download this zip on your iPhone and unzip it in the Files app
   (tap the zip file to expand it).
2. Open `spanish-master-deck-offline.html` — the deck runs entirely offline.
3. Optional: in Safari, open the file and use Share → Add to Home Screen
   for an app-like icon.

¡Buena suerte!
